# Module: root
**Role:** Package `sff` at the module root — full read/write support for MUGEN/Ikemen GO `.sff` sprite sheet files, v1 and v2, plus palette resolution (including external `.act` overrides). Migrated as-is from `character`'s internal `sff/` package (backlog item 001), stdlib-only, no dependency on `character`.
**Files:** `sprite.go` (shared data model), `v1.go`/`pcx.go`/`v1_serializer.go`/`pcx_encoder.go` (v1 read/write), `v2.go`/`v2_decoder.go`/`v2_serializer.go`/`v2_encoder.go` (v2 read/write), `palette.go` (palette resolution + `.act` overrides), `load.go` (version-agnostic full-file load), `resolve_sprite.go` (one-call sprite-to-pixels combinator), `version.go`
**Exports:** `Load`, `ResolveSpritePixels`, `ParseV1`/`ParseV2`, `DecodePCX`/`EncodePCX`, `ResolveV1Pixels`, `DecodeV2Sprite`/`EncodeV2Sprite`, `DecodeV1Palette`/`DecodeV2Palette`/`DecodeExternalPalette`, `ResolveV1Palette`/`ResolveV2Palette`, `ResolvePixels`, `SerializeV1`/`SerializeV2`, types `Sprite`/`SpriteGroup`/`Palette`/`AlphaRule`/`PCXImage`/`V2Image`/`V1SpriteTable`/`V2SpriteTable`/`V1WriteSprite`/`V2WriteSprite`/`V2WritePalette`, `Version` (string constant) — see `docs/api.md` for the full surface
**Depends on:** nothing (stdlib-only: `encoding/binary`, `image`, `image/color`, `image/png`, `io`)
