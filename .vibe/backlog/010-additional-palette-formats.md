# Import and export more palette formats

## Description
Only .act is supported for external palettes. Community tools also use JASC .pal, and indexed PNG palettes; add import/export so palette work is not tied to one format.

## Acceptance Criteria
- [ ] JASC-PAL import and export with round trip
- [ ] Palette extraction from an indexed PNG
- [ ] Malformed files produce clear errors
